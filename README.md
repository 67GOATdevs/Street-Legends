# 🏎️ Street Legends

A fast-paced neon-themed driving game where you navigate city traffic and rack up points. Survive the night ride!

## 🚀 Quick Start

### Option 1: One Command (Easiest)
```bash
npm install && npm start
```
Then open: **http://localhost:3000**

### Option 2: Step by Step
```bash
# 1. Install dependencies
npm install

# 2. Start the server
npm start

# 3. Open your browser to http://localhost:3000
```

## 🎮 How to Play

**Goal:** Navigate through traffic and avoid collisions to score points.

### Controls
- **Steer Left:** `A` or `←`
- **Steer Right:** `D` or `→`
- **Accelerate:** `W` or `↑`
- **Brake:** `S` or `↓`
- **Start Game:** Click "Start Ride" button

### Gameplay
- Avoid red and orange traffic vehicles
- Each vehicle you safely pass = 1 point
- Collision = Game Over
- Your best score is saved automatically

## 📊 Game Stats
- **Score:** Points for each vehicle dodged
- **Best:** Your highest score (stored in browser)
- **Speed:** Current vehicle speed

## 🛠️ Technical Details

**Tech Stack:**
- Vanilla JavaScript
- HTML5 Canvas
- Node.js server

**Files:**
- `index.html` - Game page
- `style.css` - Styling
- `script.js` - Game logic
- `server.js` - Local server
